# Pm钷

ClassIsland 综合增强插件。

名字致敬 Minecraft 的 **Sodium（钠）** —— 钠是 Na，钷是 Pm，都是元素。那个模组靠重写渲染管线提速；**Pm钷 走的是另一条路**：从多个角度把 ClassIsland 变得更好用。

## 状态

🚧 早期开发中，功能清单待定。

## 环境要求

- ClassIsland 2.0.0.1 ~ 2.1.x（API 版本 `2.0.0.0`）
- Windows / Linux / macOS
