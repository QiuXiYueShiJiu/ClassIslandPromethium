## 先读这一段

**网络数据不代表真实天气信息。** 本插件的天气数据全部来自第三方公开接口，只作参考，请以气象台正式发布的信息为准。

**本插件的「报警」不是气象台发布的预警信号。** 气象台发预警要经过人工会商，一个插件只能拿预报数值去比你自己设的阈值，所以文案里用的字眼是「报警」。

## 更好的天气

插件在设置窗口里新增了一个入口 **「Pm优化」**，其下第一页就是「更好的天气」；同时在主界面提供了一个同名组件。

### 关注位置

- **地图选点**：拖动平移、滚轮缩放（以光标为锚点）、点一下即取经纬度，精确到街道
- **经纬度手填**：支持到小数点后四位，改完立刻重新取数
- **按地名搜索**：可以直接搜「xx镇」「xx街道」「xx村」，选中即用
- **地点名反查**：由 OpenStreetMap 逆地理编码回填，能细到街道一级

> 「精确到街道」指的是**地点名**能到街道一级。天气预报本身是按格点计算的，
> 分辨率到不了街道，这两件事不要混为一谈。

### 地图底图

底图可选，也可以交给「自动」按优先级试：

| 顺序 | 底图 | 坐标基准 | 说明 |
|---|---|---|---|
| 1 | **高德** | GCJ-02 | 国内可用性好，实测取到真图 |
| 2 | **百度** | BD-09 | ⚠️ **未经验证**：百度的瓦片编号不是标准 XYZ，开发环境按这个地址取回来的是空白占位图，没能核对对齐。建议改用「自定义地址」填你手上可用的 |
| 3 | **腾讯** | GCJ-02 | ⚠️ 同样**未经验证**：开发环境取到的是空白占位图 |
| 4 | **OpenStreetMap** | WGS84 | 国外可达性好，国内经常连不上 |

自动模式下前一个源连续失败若干张就自动换下一个，所以哪家不通都不会卡死。
也可以指定某一家、填自定义地址模板（支持 `{s}` `{z}` `{x}` `{y}` `{key}`），或者干脆不用底图
——不用底图时只画经纬网格和标记点，照样能点选和填经纬度。

**关于坐标基准（这一条容易出大错）**：国内地图服务不直接用 GPS 的 WGS84 坐标。
高德、腾讯用 GCJ-02（火星坐标），百度在它之上再偏一次得到 BD-09。
把 WGS84 的点直接画到 GCJ-02 的底图上，在北京会偏出**四五百米**——
对「精确到街道」的选点器来说这个偏差不能忍。

本插件的处理是：**配置里永远只存 WGS84**，投影到屏幕前按当前底图的基准换算，点选回来再换回 WGS84。
所以你换个底图，已经选好的点不会被挪走；拿去查天气的也始终是 WGS84。

### 天气数据源

一共内置 **15 个**数据源，设置页里随时切换。下拉框里会标出每个源的覆盖范围。

**免密钥，装上就能用：**

| 数据源 | 覆盖 | 说明 |
|---|---|---|
| **Open-Meteo**（默认） | 全球 | 直接按经纬度查，返回 WMO 标准码，映射关系清楚 |
| **MET Norway** | 全球 | 挪威气象研究所，数据质量高；不提供体感温度，插件会退化成用气温显示 |
| **wttr.in** | 全球 | 配置最省事，但它本身是聚合服务，底层数据源不透明，数值偶尔和别家对不上 |
| **7Timer** | 全球 | 免密钥，但**短板明显**：是 3 小时一档的预报不是观测，「当前」最多能差 3 小时；风速只给蒲福风级；降水量给的是等级码不是毫米，所以本插件**不取它的降水量** |
| **NWS** | **仅美国** | 美国国家气象局官方数据，质量高、免密钥。美国以外的坐标会直接给出提示 |
| **DWD 德国** | **仅德国** | 德国气象局观测，经纬度直查。不给当日温度范围和体感温度 |
| **NEA 新加坡** | **仅新加坡** | 新加坡国家环境局。它**没有天空状况字段**，所以天气现象只能靠有没有降雨推断，多数时候显示「未知」 |
| **爱沙尼亚** | **仅爱沙尼亚** | 爱沙尼亚气象局。一次拉回全国站点挑最近的，观测站较稀疏（实测塔林最近站在 5 公里外） |

**这几个国家级数据源有个共同点：只覆盖本国，而且会自己判距离。** 用境外坐标去查，
它们不会默默返回本国天气，而是明确告诉你「最近的观测站在 X 公里外」。
这个守卫是必须的——NEA 对任意坐标都会正常返回新加坡的读数，不自己判距离的话，
北京用户选了它就会看到新加坡的天气，界面上还完全看不出异常。

**需要你自己的密钥**（免费额度一般够个人用，设置页里有「申请密钥」按钮直接跳转）：

| 数据源 | 覆盖 | 说明 |
|---|---|---|
| **和风天气** | 全球，国内优化 | 国内可用性最好，中文描述、数据细。⚠️ 它给账号分配专属 API Host 时本预设可能连不上 |
| **心知天气** | 全球，国内优化 | 国内另一家常用服务，中文描述 |
| **OpenWeatherMap** | 全球 | 最老牌的一家。当前天气接口不含当日温度范围 |
| **WeatherAPI** | 全球 | 一次请求同时给当前天气和当天温度范围，还直接给白天黑夜标志 |
| **Weatherbit** | 全球 | 当前天气接口不含当日温度范围 |
| **Visual Crossing** | 全球 | 一次请求给当前天气、当天温度范围和日出日落 |
| **Tomorrow.io** | 全球 | 给数值天气码。免费额度偏紧，适合当备选 |

**探过但没能收录的（如实列出，免得有人以为是漏了）：**

| 服务 | 国家/地区 | 为什么没收 |
|---|---|---|
| 阿根廷 SMN | 阿根廷 | 接口能通，但**数据停留在 2022-07-26，距实测时已 1528 天**。拿它当实时天气就是谎报，坚决不要 |
| SMHI | 瑞典 | 接口改版，原地址全部 404 |
| Met Éireann | 爱尔兰 | 观测里不含站点坐标，得另外维护一张站点表 |
| BOM | 澳大利亚 | 只支持按地名搜索，不支持经纬度 |
| GeoSphere | 奥地利 | 只接受站点编号，不接受经纬度 |
| IPMA | 葡萄牙 | 站点坐标与观测分两个文件，观测那个有 1 MB |
| FMI / 土耳其 MGM / KNMI / MeteoSwiss | 芬兰 / 土耳其 / 荷兰 / 瑞士 | 需要密钥，或被 WAF 直接拦掉 |
| 巴西 INMET | 巴西 | 接口路径已变更，原地址 404 |

密钥**按数据源分别保存**，在几个源之间来回切不用反复粘贴。没填密钥时会直接给出
「该数据源需要 API 密钥」的提示，而不是甩一个看不懂的 401。

> ⚠️ **诚实交代验证程度**：上面 5 个免密钥源，每个都用真实请求跑通过、解析结果逐项核对过。
> 7 个需要密钥的源，我**只验证到「接口地址与参数名正确、缺密钥时行为正确」**——
> 真实解析没有密钥没法实测。如果你在用其中一个，发现解析不对，说一声我来修。
>
> ⚠️ 这些接口的连通性在**国内网络环境下未经充分验证**。开发机不在国内，
> 测出来的延迟不代表你机器上的表现。如果某个源用不了，换一个即可。

### 图标显示方式

四种画法，随便挑：

| 方式 | 说明 |
|---|---|
| 系统图标 | 使用系统图标字体里的天气字形，码位取自 FluentAvalonia 的 `Symbol` 枚举，可回溯 |
| emoji | 指定字体渲染（默认 `Segoe UI Emoji`），字体缺失会显示成方块 |
| 自定义图片 | 按文件名从指定目录取图 |
| 纯文字 | 不画图标 |

自定义图片的命名约定：

```
clear.png       partlycloudy.png   cloudy.png     overcast.png
fog.png         haze.png           drizzle.png    rain.png
heavyrain.png   sleet.png          snow.png       thunderstorm.png
hail.png        unknown.png
```

夜间版本在名字后加 `_night`，例如 `clear_night.png`。找不到 `_night` 时会回退到白天那张，
所以只准备一套图也能用。

### 显示模式

在组件自己的设置里（右键主界面组件 → 设置）挑一个预设：

| 模式 | 显示内容 |
|---|---|
| **标准** | 天气、气温、今日温差、湿度、位置名 |
| **紧凑** | 只留图标、气温、天气 |
| **详细** | 能显示的全都显示（含风力、体感温度） |
| **自定义** | 完全听逐项开关的 |

选预设时逐项开关不参与计算 —— 否则会出现「选了紧凑、却因为某个开关还开着而多显示一项」
这种说不清的状态。想一项一项抠，就选「自定义」。

### 报警

报警模式四选一：**关闭** / **只弹提醒** / **只实时显示** / **提醒 + 实时显示**。

「提醒」走 ClassIsland 自己的通知系统，所以遮罩、悬浮、朗读、免打扰这些你已经在用的设置自动生效，
也能在 CI 的通知设置里单独关掉本插件。「实时显示」只在主界面组件上挂一行字和图标，不打扰你。

触发条件是明摆着的阈值，全部基于数据源的真实返回值：

| 项目 | 判断依据 |
|---|---|
| 高温 | 今日最高温（与当前气温取较大者）≥ 阈值 |
| 低温 | 今日最低温（与当前气温取较小者）≤ 阈值 |
| 大风 | 当前风速 ≥ 阈值 |
| 强降水 | 数据源给的**当前时段**降水量 ≥ 阈值（不是全天累计） |
| 雷暴 | 当前天气为雷阵雨 |
| 大雾/霾 | 当前有雾或有霾 |

同一类报警**同一天只报一次**，不会到点刷新就弹一遍。

### 文案变量

提醒文案和实时显示文案都支持变量，认不出来的变量会**原样保留**，方便你发现写错了名字。

```
{位置} {标题} {详情} {天气} {温度} {体感} {湿度}
{风力} {风向} {最高} {最低} {数据源} {时间}
```

### 提示音

留空则使用 ClassIsland 通知自己的提示音。指定自定义音频文件后会用它播放，
同时自动关掉宿主那一声，避免两个声音叠在一起响。

## 环境要求

- ClassIsland 2.0.0.1 ~ 2.1.x（API 版本 `2.0.0.0`）
- Windows / Linux / macOS

## 构建与打包

```bash
dotnet build src/ClassIsland.Promethium/ClassIsland.Promethium.csproj -c Release
./tools/pack.sh          # 产物：dist/Pm-<版本>.cipx
```

## 自检

仓库自带一个校验台，会真实拉起 Avalonia（headless）确认三个视图的 XAML 能加载，
跑报警判定、描述归一化、单位换算、密钥守卫、模板、取图约定、显示模式、配置存盘的断言，
并**联网实测每个免密钥数据源**（各自用所在国的坐标），验证「只覆盖本国的源会不会
如实告知境外坐标」，还钉住了底图与坐标基准的若干回归用例（80 项断言）：

```bash
dotnet run --project tests/PmXamlCheck/PmXamlCheck.csproj -c Release
```
