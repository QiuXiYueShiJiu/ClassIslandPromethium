## 先读这一段

**网络数据不代表真实天气信息。** 本插件的天气数据全部来自第三方公开接口，只作参考，请以气象台正式发布的信息为准。

**本插件的「报警」不是气象台发布的预警信号。** 气象台发预警要经过人工会商，一个插件只能拿预报数值去比阈值，所以文案里用的字眼是「报警」。

**地震速报是事后速报，不是震前预警。** 详见下面「地震速报」一节，这一条请务必看清。

## 更好的天气

插件在设置窗口里新增了一个入口 **「Pm优化」**，其下第一页就是「更好的天气」；同时在主界面提供了一个同名组件。

### 关注位置

天气和地震速报共用同一个位置，地震那块刻意没有单独的位置设置，避免两边对不上。

- **地图选点**：拖动平移、滚轮缩放（以光标为锚点）、点一下即取经纬度，精确到街道
- **经纬度手填**：支持到小数点后四位，改完立刻重新取数
- **按地名搜索**：可以直接搜「xx镇」「xx街道」「xx村」，选中即用
- **地点名反查**：由 OpenStreetMap 逆地理编码回填，能细到街道一级

> 「精确到街道」指的是**地点名**能到街道一级。天气预报本身是按格点计算的，
> 分辨率到不了街道，这两件事不要混为一谈。

### 数据源

三个都是免密钥的公开接口，可在设置页随时切换：

| 数据源 | 说明 |
|---|---|
| **Open-Meteo**（默认） | 直接按经纬度查询，返回 WMO 标准码，映射关系清楚 |
| **MET Norway** | 挪威气象研究所，数据质量高；不提供体感温度，插件会退化成用气温显示 |
| **wttr.in** | 配置最省事，但它本身是聚合服务，底层数据源不透明，数值偶尔和别家对不上 |

> ⚠️ 这些接口的连通性在**国内网络环境下未经充分验证**。开发机不在国内，
> 测出来的延迟不代表你机器上的表现。如果某个源用不了，换一个即可。

### 图标显示方式

四种画法，随便挑：

| 方式 | 说明 |
|---|---|
| 系统图标 | 使用系统图标字体里的天气字形，码位取自 FluentAvalonia 的 `Symbol` 枚举，可回溯 |
| emoji | 指定字体渲染（默认 `Segoe UI Emoji`），字体缺失会显示成方块 |
| 自定义图片 | 按文件名从指定目录取图 |
| 纯文字 | 不画图标 |

自定义图片的命名约定：

```
clear.png       partlycloudy.png   cloudy.png     overcast.png
fog.png         haze.png           drizzle.png    rain.png
heavyrain.png   sleet.png          snow.png       thunderstorm.png
hail.png        unknown.png
```

夜间版本在名字后加 `_night`，例如 `clear_night.png`。找不到 `_night` 时会回退到白天那张，
所以只准备一套图也能用。

### 显示模式

在组件自己的设置里（右键主界面组件 → 设置）挑一个预设：

| 模式 | 显示内容 |
|---|---|
| **标准** | 天气、气温、今日温差、湿度、位置名 |
| **紧凑** | 只留图标、气温、天气 |
| **详细** | 能显示的全都显示（含风力、体感温度） |
| **自定义** | 完全听逐项开关的 |

选预设时逐项开关不参与计算 —— 否则会出现「选了紧凑、却因为某个开关还开着而多显示一项」
这种说不清的状态。想一项一项抠，就选「自定义」。

### 报警

报警模式四选一：**关闭** / **只弹提醒** / **只实时显示** / **提醒 + 实时显示**。

「提醒」走 ClassIsland 自己的通知系统，所以遮罩、悬浮、朗读、免打扰这些你已经在用的设置自动生效，
也能在 CI 的通知设置里单独关掉本插件。「实时显示」只在主界面组件上挂一行字，不打扰你。

触发条件是明摆着的阈值，全部基于数据源的真实返回值：

| 项目 | 判断依据 |
|---|---|
| 高温 | 今日最高温（与当前气温取较大者）≥ 阈值 |
| 低温 | 今日最低温（与当前气温取较小者）≤ 阈值 |
| 大风 | 当前风速 ≥ 阈值 |
| 强降水 | 数据源给的**当前时段**降水量 ≥ 阈值（不是全天累计） |
| 雷暴 | 当前天气为雷阵雨 |
| 大雾/霾 | 当前有雾或有霾 |

同一类报警**同一天只报一次**，不会到点刷新就弹一遍。

### 文案变量

提醒文案和实时显示文案都支持变量，认不出来的变量会**原样保留**，方便你发现写错了名字。

**天气报警：** `{位置}` `{标题}` `{详情}` `{天气}` `{温度}` `{体感}` `{湿度}` `{风力}` `{风向}` `{最高}` `{最低}` `{数据源}` `{时间}`

**地震速报：** `{地点}` `{震级}` `{深度}` `{距离}` `{震感}` `{时间}` `{来源}` `{链接}`

### 提示音

留空则使用 ClassIsland 通知自己的提示音。指定自定义音频文件后会用它播放，
同时自动关掉宿主那一声，避免两个声音叠在一起响。

## 地震速报

默认**关闭**，需要你自己打开。

### 它能做到的

关注范围内发生地震、且按经验规则判断可能有震感时，弹出提醒并在组件上实时显示。
位置跟随「更好的天气」里选的点。文案和音效都可以自定义，支持变量。

- 数据源：**USGS**（默认）/ **EMSC**，都是公开地震目录，免密钥，可切换
- 触发条件：目录里真实存在 + 在关注半径内 + 达到最低震级 + 判断可能有震感，**四条缺一条都不报**
- 按事件编号去重并持久化，插件重启不会把同一次地震再报一遍

### 它做不到的

**这不是地震预警。** 地震要等台网记录、定位、定级之后才会进目录，
所以拿到消息时地震往往已经发生完了。真正意义上的地震预警需要密集台网和专用推送通道，
一个插件做不到，任何声称能做到的插件都值得怀疑。

另外，USGS 与 EMSC 对**国内小震**的记录可能不全，漏报是正常现象。

### 关于「震感」

界面上的震感判断（可能有明显震感 / 可能有轻微震感 / 基本无感）是一条
**按震级和震中距写的经验规则**，不是烈度评定。真正的烈度还要考虑震源机制、深度、
场地条件、土层放大等等，光凭震级和距离给不出那个精度。

设计上宁可漏报也不报假消息：规则卡得偏保守，而且必须同时满足上面四个条件才会出声。

## 环境要求

- ClassIsland 2.0.0.1 ~ 2.1.x（API 版本 `2.0.0.0`）
- Windows / Linux / macOS

## 构建与打包

```bash
dotnet build src/ClassIsland.Promethium/ClassIsland.Promethium.csproj -c Release
./tools/pack.sh          # 产物：dist/Pm-<版本>.cipx
```

## 自检

仓库自带一个校验台，会真实拉起 Avalonia（headless）确认三个视图的 XAML 能加载，
跑报警判定、震感边界、模板、取图约定、配置存盘的断言，
并**联网实测每个数据源**，用真实返回来验证解析逻辑：

```bash
dotnet run --project tests/PmXamlCheck/PmXamlCheck.csproj -c Release
```
